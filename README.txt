IT-CONSULTING — сайт видеонаблюдения
=====================================

Файлы:
- index.html — главная страница
- style.css — дизайн
- script.js — интерактивность
- robots.txt — инструкции поисковикам
- sitemap.xml — карта сайта

ВАЖНО:
1. В index.html замените https://it-consulting.kz/ на фактический адрес сайта, если пока не используете этот домен.
2. Форма заявки сейчас открывает WhatsApp, поэтому отдельный сервер не нужен.
3. Сайт можно бесплатно разместить через GitHub Pages.
4. После публикации добавьте адрес сайта в Google Search Console и отправьте sitemap.xml.
